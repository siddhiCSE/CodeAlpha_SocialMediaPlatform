# IdeaSphere 💡

IdeaSphere is a social platform where users can share ideas, discover new concepts, and connect with others**.

## ✨ Features

* Create and share ideas
* Explore ideas from other users
* Like and comment on posts
* User profiles
* Responsive design

## 🛠️ Tech Stack

* React
* TypeScript / JavaScript
* Tailwind CSS
* Vite
* Supabase

## 🚀 Run Locally

```bash
npm install
npm run dev
```

Then open:

```text
http://localhost:5173
```
